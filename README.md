# 🧠 About

**station404** is a terminal-based underground penetration testing framework designed with a cinematic station-style interface.

The project combines:
- ethical hacking utilities
- reconnaissance tools
- vulnerability scanners
- exploitation modules
- anonymity systems
- underground terminal aesthetics

inside a single command-line environment.

Unlike traditional tool launchers, **station404** focuses heavily on:
- atmosphere
- terminal experience
- dark underground design
- categorized workflows
- immersive navigation system
